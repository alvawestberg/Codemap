01 / HTML

Bygg strukturen med HTML.

HTML står för HyperText Markup Language. Det används för att skapa strukturen och innehållet på en webbsida.

Vad används HTML till?

  • Rubriker och text
  • Bilder och länkar
  • Listor och formulär
  • Strukturen på en webbsida 
<h1>Hej världen!</h1>

<p>Min första webbsida.</p>

02 / CSS

Designa med CSS.

CSS står för Cascading Style Sheets. Med CSS kan du ändra färger, storlekar, avstånd och layout på en webbsida.

Vad används CSS till?

  • Färger och typsnitt
  • Layout och placering
  • Responsiv design
  • Animeringar och effekter 
h1 {
    color: #9b5cff;
    font-size: 40px;
}

03 / JAVASCRIPT

Gör sidan interaktiv.

JavaScript används för att skapa interaktioner och funktioner på webbsidor.

Vad används JavaScript till?

  • Knappar och menyer
  • Quiz och spel
  • Interaktiva funktioner
  • Ändra innehåll på sidan 
const message = "Hej!";

console.log(message);

04 / PYTHON

Programmera med Python.

Python är ett programmeringsspråk som är relativt enkelt att börja med. Det används bland annat inom spel, AI och datahantering.

Vad används Python till?

  • Spelutveckling
  • Artificiell intelligens
  • Datahantering
  • Automatisering 
message = "Hej världen!"

print(message)
